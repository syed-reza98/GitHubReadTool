# CBRMS (Records / Business Management System)

Overview

A records/case management application built with raw PHP focusing on CRUD operations and structured data handling.

Code

- Raw PHP codebase with modular includes, procedural patterns, and MySQL for storage.

Architecture

- Monolithic PHP application with separate modules for records, users, and reporting.

Tech stack

- PHP (Raw), MySQL, JavaScript

Status

- Core CRUD features implemented for business records management.
