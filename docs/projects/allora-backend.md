# Allora Backend

Overview

Laravel-based REST API service skeleton for e-commerce or digital product delivery using Laravel Filament for admin UI.

Code

- Laravel REST endpoints, organized controllers, and Blade views where needed. Filament used for admin CRUD panels.

Architecture

- API-first service with MVC separation and Filament for quick admin CRUD interfaces.

Tech stack

- PHP (Laravel), Filament, MySQL

Status

- Baseline backend ready for extension into product ordering and delivery flows.
