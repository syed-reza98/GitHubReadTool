# Sharothee Wedding

Overview

Custom event/wedding website with guest-facing pages, RSVP, media galleries, and admin content management.

Code

- Frontend: Next.js (React) with TypeScript and Tailwind CSS.
- Backend: API routes (Next.js) or separate backend for admin features.

Architecture

- Server-side rendering for public pages, API for RSVP submissions and admin operations, and static assets for media.

Tech stack

- TypeScript, Next.js, Tailwind CSS, Vercel (optional) for hosting

Status

- Delivered site with content management features and responsive UI.
