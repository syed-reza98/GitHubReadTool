# NetCon

Overview

A modular web application combining a Python backend API with a Vue.js single-page application for interactive data visualization and componentized UI.

Code

- Backend: Python (Flask or Django) exposing REST endpoints.
- Frontend: Vue.js SPA for dashboards and interactive components.

Architecture

- API-first backend with separated static frontend build deployed on CDN or integrated via reverse proxy.

Tech stack

- Python (Flask/Django), Vue.js, REST APIs, Docker (optional)

Status

- Modular codebase for data-driven interactive applications.
