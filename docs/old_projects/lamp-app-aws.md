# LAMP-APP-AWS

Overview

Reusable LAMP scaffold to quickly bootstrap PHP/MySQL applications with common patterns like authentication and CRUD.

Code

- PHP codebase following MVC-ish structure and helpers for authentication and session management.

Architecture

- LAMP stack deployable on AWS (EC2 / Lightsail) with scripted setup for web server and database.

Tech stack

- PHP, MySQL, Apache/IIS, Bash (deployment scripts), AWS

Status

- Template and scaffold used across internal projects to speed up development.
