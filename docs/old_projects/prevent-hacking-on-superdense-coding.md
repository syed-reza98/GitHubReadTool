# Prevent Hacking on Superdense Coding

Overview

Research / prototype focusing on securing superdense coding communication channels against eavesdropping using quantum circuits and automated error correction.

Code

- Implementations use Qiskit with custom circuits to detect eavesdropping and apply error-correction schemes.
- Experimental integration with IBM Quantum API for simulation and limited real-device runs.

Architecture

- Quantum circuit prototypes + classical orchestration for error detection and correction.

Tech stack

- Python, Qiskit, IBM Quantum API, Machine Learning for anomaly detection in quantum signals.

Status

- Prototype stage with proofs-of-concept for eavesdropping detection and correction automation.
